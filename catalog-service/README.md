# Catalog Service

Servicio REST de catálogo para la práctica Composite API. Expone
`GET /microservices/products/{id}` en el puerto `8081` y proporciona el producto
de prueba `P-101`.

Desde esta carpeta, inicia el servicio con `..\digital\mvnw.cmd spring-boot:run`
y ejecuta sus pruebas con `..\digital\mvnw.cmd test`.
